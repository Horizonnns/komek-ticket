# Komek Ticket

Система бронирования и покупки билетов в кино, реализованная как PWA.

## Реализованный функционал

-   **Бронирование**: Интерактивная сетка зала с выбором мест и расчетом стоимости в реальном времени.
-   **Личный кабинет**: Сохранение билетов в LocalStorage, генерация персональных QR-кодов через API.
-   **Оплата**: Модуль оплаты с валидацией банковских карт, форматированием ввода и имитацией обработки платежа.
-   **Статус билетов**: Система обновления статуса билета («Оплачено») после успешной транзакции с визуальной индикацией.
-   **PWA**: Поддержка установки на устройства, манифест и Service Worker со стратегией кэширования Stale-While-Revalidate.
-   **Фильтрация**: Календарь и фильтр сеансов по кинотеатрам на главной странице.
-   **Адаптивность**: Полная поддержка мобильных устройств, планшетов и десктопов.
-   **Уведомления**: Система Toast-сообщений для обратной связи с пользователем.

## Архитектура

-   **StorageService**: Единый сервис для управления данными в LocalStorage.
-   **Modular JS**: Логика разбита на независимые TypeScript-модули.
-   **SCSS**: Модульная структура стилей с использованием переменных и BEM.

## Запуск

1. `composer install`
2. `npm install`
3. `php artisan serve`
4. `npm run dev`
